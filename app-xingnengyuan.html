应用介绍

星能元（XLY）是一门中文编程语言及其移动端集成开发环境：语法、格式、缩进规则与 Python 3.x 完全一致，仅将关键字与常用函数名改为中文。会 Python，就会星能元。应用内置代码编辑器、一键运行、文件管理与帮助文档，在手机上即可编写、运行和分享中文程序。

语言特色：中文 · 英文 · 中英混写，全支持

  • 纯中文编写：打印、如果、否则、对于、当、定义、类、返回、导入等 40 余个关键字与内建函数全部中文化，写代码如写自然语言；
  • 纯英文编写：所有中文关键字与函数名均配有英文别名（打印 = print、范围 = range、数学 = math……），标准 Python 代码可直接运行；
  • 中英混写：中文与英文关键字、函数名可在同一程序中混合使用，例如「对于 i 在 range(5)」「如果 score >= 90」，随心切换；
  • 中文变量名：标识符支持中文，姓名 = "星能元" 完全合法；
  • 语法零迁移：缩进、冒号、推导式、装饰器、f-string 等规则与 Python 3.x 一致，Python 学习者零成本上手。
# 纯中文
对于 i 在 范围(5):
    打印(i, "是偶数")

# 纯英文（同样可运行）
for i in range(5):
    print(i, "even")

# 中英混写
如果 score >= int(input):
    打印("优秀")

功能特色

  • 中文关键字体系：40+ 关键字与内建函数中文化，附完整中英文对照表；
  • 代码编辑器：关键字高亮、多文件管理、深色 / 浅色主题；
  • 一键运行：即时编译执行，控制台输出与错误提示；
  • 内置模块：数学、随机、时间、文件、线程、图形、json、正则、日期时间、系统、base64、哈希；
  • 图形画布：支持绘制线、矩形、圆、椭圆、弧线、文本与多边形；
  • 虚拟文件系统：应用内沙箱持久化存储，数据本地保留；
  • 完整语言手册：20 章手册内置可查，亦支持在线预览与下载。

使用方式

  1. 下载并安装星能元（手机版或桌面版）；
  2. 新建脚本，用中文、英文或中英混写编写程序；
  3. 点击「运行」查看结果，文件自动保存于应用内文件管理。

不确定某个关键字怎么写？打开下方「在线预览手册」，或点击应用内帮助文档随时查阅中英文对照表。

声明与风险提示

星能元运行于移动端 WebView 环境，线程为协作式并发（适合睡眠、网络、输入类任务），不等同于桌面端原生多线程性能。

文件系统为应用内虚拟沙箱，数据持久化保存于应用空间，非安卓真实磁盘；卸载应用将同时清除其中的文件。

网络请求受 WebView 网络策略限制，部分目标站点可能需要支持 CORS。

本项目按「现状」提供，不承诺完全无错误。请在合法合规的前提下使用，不得用于任何违法用途。
