二十、注意事项

  1. 生成器与尝试：生成器（产出）内部暂不支持包含「产出」的「尝试」块
  2. 字节串与字符串：不自动互转，需 字节串(文本) / 字节串.解码()
  3. 线程模型：真多线程受限（JS 单线程模型），线程为协作式并发，适合睡眠/网络/输入类任务
  4. 文件系统：为应用内虚拟沙箱，非安卓真实磁盘
  5. 网络请求：受 WebView 网络策略限制，可能需要目标站点支持 CORS
  6. 英文兼容：英文关键字与内建函数名同样可用，兼容标准 Python 代码
